## Why the failing launch matters, and what is known about it

- **Observed:** liveness, then silence for 900 s. Its two siblings in the same mode completed in
  28.5–29.0 s of wall time, with the probe running ~26 s inside the event page.
- **Across all 42 completed recorded Firefox launches**, no probe ran longer than **28.0 s** inside
  the event page.
- **Diagnostic** (`logs/diagnostic-firefox-event-page-lifetime.json`, decides nothing): the same
  probe made to run past 30 s never reported at Firefox defaults (**4 / 4**, both candidates), and
  reported correctly every time with only `extensions.background.idle.timeout` raised (**4 / 4**,
  probes of 41–48 s).
- **Therefore:** at default prefs, Firefox 155.0.1 does not let a probe this long complete in an
  MV3 event page. The failing launch shows exactly that symptom, and TR-02's Linux probes ran close
  to the limit. **Its own cause was not directly observed**, and the verdict is not changed by the
  diagnostic.
