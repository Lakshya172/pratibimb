## What this authorises

- **Recording the rejection**, done in `agentos/registry/model-registry.md` under a new *Rejection
  record*, with the artifact's hash, per blocking rule 5.
- **Citing S-04a-1a as run**: on a realistic text-bearing input the pinned detector's WASM output
  agrees with native to 4.23e-06.
- **Citing the conversion as reproducible**: pinned source hashes, recorded toolchain, a functional
  match to the S-04a-1 artifact at 9.5e-06, and two byte-identical end-to-end runs.

## What this does not authorise

- Adoption, integration, a product change, or an OCR capability of any kind.
- Moving the localisation threshold, re-scoring this fixture under a new criterion, or re-running the
  post-processing until it passes.
- Using `PP-OCRv5_mobile_rec`. It emits characters and remains **REJECTED** for this role.
- Leaving the isolated measurement venv as a project dependency. It lives in the session scratchpad,
  outside the repository, and nothing references it but this record.

## Open, and stated

1. **The failing criterion may be measuring a convention rather than detection.** DB returns padded
   line boxes; the ground truth is `measureText`'s tight ink box. Every string in the canvas was found
   and both secrets were fully covered, yet the IoU is capped near 0.47 by box height alone. If the
   owner judges that localisation for a *redaction* detector should be defined differently, that is a
   new criterion. It must be **pre-registered and evaluated on a held-out set that this candidate has
   not been seen on** — this fixture's result is known now and cannot serve as an unbiased test.
   Until then, the verdict stands.
2. **How the two WASM rows combine for QG-03** is a gate-owner judgement. It is moot for this
   candidate.
3. **Latency** is about 2× S-04a-1's recorded figure for the same input shape. Representation and
   cross-origin isolation are ruled out as causes; no cause is claimed.
4. **The canvas identifier is still neither read nor protected** in the product.

## Next step, per the owner's rule for a rejection

**Inventory a different legitimate text-region candidate under the same acceptance process.** M7
established that the repository holds no second candidate, so this is a new model-adoption exercise.
Any candidate must: locate text without recognising it, have its licence verified at a pinned
revision, avoid a new build dependency or come with an ADR for one, pass the frozen WASM rule, and be
screened against the pre-registered criteria — and then, if it passes, go through QG-03 on a held-out
set before anything is integrated.
