## Native baseline (Part C)

One `[1,1,H,W]` float32 output per input; five inferences per input byte-identical.

| input | shape fed | output | native p50 (ms) |
|---|---|---|---|
| synthetic (S-04a-1) | 1×3×640×640 | 1×1×640×640, **identically zero** | — |
| development fixture | 1×3×736×1312 | 1×1×736×1312 | 108 / 90 (run1 / run2) |
| H1–H6 | 1×3×736×1312 each | 1×1×736×1312 each | recorded per run |

Preprocessing is the model's own `inference.yml`, which declares `DetResizeForTest` **without
arguments**. The operator's upstream defaults apply (PaddleOCR `operators.py` at `dab3fe35`):
`limit_side_len 736`, `limit_type min`, sides rounded to the **nearest** multiple of 32, so
720×1280 becomes **736×1312**. That is 1.47× TR-01's input pixels. It was fixed in
`prep-native.py` before any run, not chosen afterwards.
